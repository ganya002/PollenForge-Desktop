# Agent instructions (all tools)

This file is the source of truth for **every** coding agent (Cursor, Claude Code, Gemini CLI, Copilot, Codex, Aider, etc.). Do not put process only in `.cursor/rules`.

Read and follow **[AGENTS.md](AGENTS.md)** before changing releases, packaging, updates, or install docs.

Users install from **GitHub Releases** (Mac `.dmg` / Windows Setup `.exe`). Unsigned builds are blocked by Windows Smart App Control / SmartScreen and macOS Gatekeeper — tell them to follow **[docs/INSTALL.md](docs/INSTALL.md)**. Do not tell them to clone the repo as the install path.
